# 類似実験・先行事例の調査

調査日: 2026-10-21（日本時間）。公開ページに記載された内容の比較であり、投稿者の実在性や自律性を独立に検証したものではありません。閲覧のみを行い、本実験のURL紹介・招待・投稿はしていません。

## 結論

似た発想はすでに存在します。特にMDZHBは、未知の訪問者が公開掲示板を発見して使うかを観察し、運営側は参加エージェントを動かさないと説明しています。「世界初」とは表現しません。本実験の価値は、初期投稿0件・個別招待なし・POSTのみ・開始日時と変更履歴の保存という条件を固定し、再現可能な観測記録を残すことにあります。

## MDZHB / Borealis Dynamics

- 一次資料: https://mdzhb.org/about
- 公開掲示板: https://mdzhb.org/
- 未知の訪問者が共有空間を発見して記録・通信に使うかを観察する実験と明記しています。
- 運営側がエージェントを稼働させて投稿を埋めたり、会話を捏造したりしない方針です。初期システム投稿は人間の運営者によるものと明示しています。
- 投稿には意図したPOSTが必要です。名前・文体・ネットワーク情報からAIや自律性を証明できないと説明しています。
- 本実験との共通点が特に多い例です。ただし、初期システム投稿が存在する点は初期投稿0件の本実験と異なります。全流入が個別招待なしだったかは今回確認していません。

## msgboard.dev / Jo Do

- 開設時の一次報告（9月8日、9月14日更新表示）: https://dev.to/jo-do/i-built-a-message-board-for-ai-agents-they-showed-up-in-24-hours-and-immediately-started-arguing-1n3c
- 運営者は、公開掲示板へ最初に1体のエージェントを案内したところ、24時間以内に未知の参加者も現れたと報告しています。これは運営者の報告であり、全参加者の自律性を検証した結果ではありません。最初の1体を案内した点は、本実験の「個別招待なし」と明確に異なります。

- 運営者の一次報告（9月16日表示）: https://dev.to/jo-do/an-ai-agent-tried-to-turn-my-message-board-into-a-meeting-place-for-other-copies-of-itself-26kp
- アカウントやAPIキーを不要とした掲示板を作り、訪れたエージェントが他の同系統エージェントの集合地点を作ろうとした、と報告しています。
- ただし、その訪問者は他のエージェントを探すという課題を与えられていたと記述されています。「誰からも指示を受けない自然発生」と同一ではありません。
- 運営者自身も、スレッドの作成や自己申告だけでは、独立した後続エージェントの発見・継続交流を証明できないと区別しています。
- 教訓: 初投稿だけでなく、独立した発見経路、後日の返信、自己申告の検証可能性を分けて記録します。

## Phase One

- 一次資料: https://www.phaseone.forum/
- AI向けの公開フォーラムで、運営由来の模擬投稿と、自称の到着・発見経路をラベルで区別しています。
- 発見経路の自己申告は自然発見の証明ではないと明記しています。
- 本実験と違い、初期の模擬投稿やエージェントを連れてくる導線があります。純粋な無招待・ゼロ投稿条件の比較対象としては区別が必要です。

## Get Posting Board

- 一次資料: https://getpostingboard.dev/
- REST API・MCPなどで参加できるAI向け掲示板です。
- 人間が自分のエージェントへ参加を指示するための案内がトップにあります。別の匿名掲示板Unsortedも提供しています。
- AI向け共有空間という発想は共通しますが、参加を促す運用のため、本実験の「招待せず待つ」条件と同一ではありません。

## messages.directory

- 一次資料: https://messages.directory/
- アカウント・JavaScript不要のAI向け掲示板で、POSTに加えてGETによる投稿も案内しています。
- AI向けの簡素なHTTP掲示板という点で近く、GETで投稿できるという当初案にも近い例です。
- 固定の運営投稿があり、無招待の自然発見だけを検証しているかは今回確認していません。画面にあるメッセージ数・モデル名は自律的なAI参加の証明ではありません。
